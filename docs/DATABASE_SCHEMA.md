# DATABASE_SCHEMA

SQLite, 28 tables, 33 indexes, 8 migrations (`packages/db/migrations`, generated by `npm run db:generate`; applied automatically by `createDb`). Foreign keys are ON; WAL + busy_timeout for file databases.

| Area | Tables |
|---|---|
| Platform | `products`, `plans`, `add_ons`, `platform_settings`, `platform_staff`, `leads`, `internal_tasks`, `audit_logs`, `counters` |
| Identity & tenancy | `tenants` (incl. currency, locale, timezone, `tax_bp`), `users`, `roles`, `role_permissions`, `memberships`, `sessions` |
| Subscriptions & billing | `subscriptions`, `subscription_events` (history, never deleted), `tenant_add_ons`, `billing_invoices`, `payment_transactions`, `webhook_events` |
| Website | `tenant_sites` (draft + published JSON), `domains` |
| Cross-cutting | `search_index`, `notifications`, `notification_outbox`, `customers` (shared example repo) |
| Product data | `records` (all ten products — see ARCHITECTURE.md §5.2) |

Conventions: UUID text ids; ISO-8601 UTC text timestamps; money = integer minor units + currency; statuses are validated strings (SQLite has no enums).

Integrity rules: unique `tenants.slug`, `users.email`, `domains.hostname`, `billing_invoices.number`, `payment_transactions.idempotency_key` and `(gateway, provider_ref)`, `webhook_events(provider, event_id)`; per-tenant unique `records(tenant_id, entity_type, code)` and `(…, unique_key)`. Financial/history tables use `ON DELETE RESTRICT`. Multi-row operations (registration, stock moves, checkout, payments, record hooks) run in transactions.

Product entities (declared in `apps/api/src/products/defs/*.ts`): medical 14 · realestate 13 · ecommerce 13 · restaurant 11 · automotive 12 · learning 14 · construction 18 · booking 10 · fleet 12 · business 16.
